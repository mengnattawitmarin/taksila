# ตักศิลา — แอปอ่านดวงจากตำแหน่งดาวจริง

เว็บแอปมือถือ ทำงานได้ทันที ไม่ต้องติดตั้งไลบรารีหรือ build tool ใด ๆ
เขียนด้วย HTML + CSS + JavaScript ล้วน (ES modules)

## เปิดใช้งาน

**แบบเร็วที่สุด** เปิดไฟล์ `dist/taksila.html` ในเบราว์เซอร์ได้เลย (ทุกอย่างรวมอยู่ในไฟล์เดียว)

**แบบนักพัฒนา** โค้ดใน `js/` เป็น ES modules ต้องเปิดผ่านเว็บเซิร์ฟเวอร์

```bash
cd taksila
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

**ขึ้นเว็บจริง** อัปโหลดทั้งโฟลเดอร์ (หรือแค่ `dist/taksila.html`) ขึ้น Netlify, Vercel, GitHub Pages หรือโฮสติ้งใดก็ได้ ไม่ต้องตั้งค่าเพิ่ม

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเริ่มต้น โหลดฟอนต์ CSS และ `js/app.js` |
| `css/styles.css` | สี ฟอนต์ และหน้าตาทุกส่วน สีทั้งหมดอยู่ที่ `:root` บรรทัดแรก ๆ |
| `js/astro.js` | **หัวใจของแอป** คำนวณตำแหน่งดาว ลัคนา ภพ มุมดาว ดาวจร ดวงรายวัน และคู่ดวง |
| `js/starmap.js` | วาดผังดาวเป็น SVG พร้อมภาพเคลื่อนไหว |
| `js/data.js` | ข้อมูลคงที่: สถานที่เกิด ไพ่ทาโรต์ 22 ใบ ความหมายตัวเลข |
| `js/app.js` | หน้าจอทั้งหมด การสลับหน้า และการบันทึกข้อมูล |
| `tools/build-single.py` | รวมทุกไฟล์เป็น `dist/taksila.html` ไฟล์เดียว |
| `tools/check-ephemeris.mjs` | ทดสอบความแม่นของการคำนวณกับเหตุการณ์ดาราศาสตร์จริง |

## ความแม่นยำของการคำนวณ

ใช้สูตรของ Paul Schlyter ("How to compute planetary positions") คำนวณตำแหน่งดาวแบบ tropical, geocentric
ใช้ได้ดีช่วงปี ค.ศ. 1900–2100 ทดสอบด้วย `node tools/check-ephemeris.mjs` คลาดเคลื่อนมากสุดราว 0.3 องศา (ดาวพลูโต)
ดาวอื่นคลาดไม่ถึง 0.1 องศา ซึ่งละเอียดพอสำหรับโหราศาสตร์

- ลัคนาคำนวณจากเวลาดาราคติท้องถิ่น ละติจูด และความเอียงของแกนโลก
- ระบบภพใช้แบบ Whole Sign (ภพละหนึ่งราศี นับจากราศีลัคนา)
- ถ้าไม่ทราบเวลาเกิด ใช้เวลาเที่ยงวัน และนับภพจากราศีดวงอาทิตย์

## แนวทางเรียนรู้ (เริ่มจากง่ายไปยาก)

1. **เปลี่ยนสีและฟอนต์** แก้ค่าใน `:root` ของ `css/styles.css` แล้วรีเฟรชดู
2. **แก้ข้อความ** คำทำนายต่าง ๆ อยู่ใน `js/data.js` และฟังก์ชัน `planetText`, `TRANSIT_TEXT`, `daily()`
3. **เพิ่มจังหวัด** เพิ่มบรรทัดใน `PLACES` ของ `js/data.js` (ชื่อ ละติจูด ลองจิจูด เขตเวลา)
4. **เพิ่มหน้าใหม่** ดูตัวอย่าง `viewLuck()` ใน `js/app.js` แล้วเพิ่มชื่อหน้าใน `VIEWS` และ `NAV`
5. **เข้าใจการคำนวณ** อ่าน `planetPositions()` และ `angles()` ใน `js/astro.js` เทียบกับเว็บของ Schlyter

## ต่อยอดให้เป็นธุรกิจ

- **เนื้อหา:** ให้โหรตรวจและเขียนคำทำนายเพิ่ม ยิ่งละเอียดยิ่งน่าเชื่อถือ
- **บัญชีผู้ใช้:** ตอนนี้ข้อมูลเก็บในเครื่องผู้ใช้ (localStorage) ถ้าต้องการซิงก์หลายเครื่อง ต้องมีระบบหลังบ้าน เช่น Supabase หรือ Firebase
- **ปรึกษา AI:** หน้า "ปรึกษา" ตอนนี้ตอบด้วยกฎจากผังดาว ต่อกับ AI API ได้ที่ฟังก์ชัน `answer()` ใน `js/app.js` (ต้องมีเซิร์ฟเวอร์เก็บ API key ห้ามใส่ key ในหน้าเว็บ)
- **รายได้:** ขายรายงานดวงฉบับเต็ม สมาชิกรายเดือน หรือนัดปรึกษาโหรจริง
- **ข้อกฎหมาย:** มีนโยบายความเป็นส่วนตัวตาม PDPA เพราะวันเวลาสถานที่เกิดเป็นข้อมูลส่วนบุคคล ห้องโชคลาภให้ระบุว่าเพื่อความบันเทิงเสมอ

คำทำนายทั้งหมดเพื่อเป็นแนวทางและความบันเทิง
