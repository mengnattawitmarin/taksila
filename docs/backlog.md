# รายการรอแก้ไข (เริ่มทำหลังเช้าวันพุธ)

พี่ส่งเรื่องใหม่มาเมื่อไหร่ จดต่อท้ายรายการนี้ ยังไม่ลงมือ

## ค้างจากรอบก่อน
- [ ] คาถาสมเด็จโต บทที่ขึ้นต้น "เกโรนะทะตะมัง" — รอพี่ส่งรูปหรือข้อความตัวบท
- [ ] จุดคะแนนใต้แถบ 7 วัน คำนวณคนละแบบกับคำตัดสินในการ์ดคำทำนาย ทำให้ตรงกัน
- [ ] บทบาลีของท้าวจตุโลกบาล (ตอนนี้มีแต่คำขอพรภาษาไทย) — หาแหล่งที่ยืนยันได้
- [ ] ข้อมูลปีชงร่วมของปี 2570 — อัปเดตก่อนตรุษจีน (ก.พ. 2570)
- [ ] ปุ่มไมค์ในห้องปรึกษา — รอผลทดสอบบนมือถือจริง (iPhone / Android)
- [ ] ให้ผู้รู้ตรวจตัวบทคาถาเกจิ เทพ และคาถาตามความเชื่อ ก่อนเปิดให้คนทั่วไปใช้

## เรื่องใหม่ที่พี่ส่งมา
- [ ] **ห้องไพ่ (26 ต.ค.)**
  - ทำให้ไพ่ 12 ภพเด่นที่สุดในหน้าแรกของห้องไพ่ (เป็นตัวเลือกหลัก ใหญ่ สะดุดตา)
  - จัด UI หน้าแรกของห้องไพ่ใหม่ให้สวยขึ้น
  - หลังเปิดไพ่ครบ เพิ่มปุ่ม "บันทึกรูป" และ "แชร์รูป" (สร้างภาพสรุปผลไพ่ ส่ง LINE หรือเก็บไว้อ่านต่อ)
